The kinds of events we run

Every format here exists to do a different job for the field:

Large hackathons

Big, open build events that show what this community is capable of when it gets in one room.

Build

Targeted hackathons

Smaller builds working directly with a single agency on one specific problem, where focused effort drives real impact.

Demo nights
